আসসালামু আলাইকুম 🌿

প্রশ্ন করুন, নতুন কিছু শিখুন, আইডিয়া তৈরি করুন। আপনি যে তথ্য মনে রাখতে বলবেন তা এই ফোনে সংরক্ষণ করে পরের কথোপকথনে ব্যবহার করা হবে।

বাংলা ও Englishডিভাইসে সংরক্ষিত স্মৃতিAPI সেটআপ প্রয়োজন
আপনার প্রথম প্রশ্নটি লিখুন।
শুরু করতে চাইলে: “নিজে নিজে শেখা আর AI memory-র পার্থক্য বোঝাও।”
আপনার বার্তা নির্বাচিত AI API provider-এ পাঠানো হয়। গোপন তথ্য পাঠাবেন না।

🧠 আমার শেখানো স্মৃতি

এগুলো আপনার ফোনে থাকে এবং কথোপকথনের সময় AI-কে প্রাসঙ্গিক তথ্য দেয়। এটি AI মডেলকে পুনরায় প্রশিক্ষণ দেয় না। “মনে রাখো: …” লিখে চ্যাট থেকেও স্মৃতি যোগ করতে পারবেন।

স্মৃতি/চ্যাট মুছে ফেললে তা ফেরত পাওয়া নাও যেতে পারে। আগে Export রাখতে পারেন।

⚙️ AI সংযোগ

এই অ্যাপ নিজে একটি ভাষা মডেল চালায় না। উত্তর তৈরির জন্য অনলাইন AI API key দরকার। ডিফল্ট সেটিংস Groq-এর OpenAI-compatible Chat Completions endpoint; নিজের provider ব্যবহার করলে তার HTTPS endpoint ও model ID বসান।

উদাহরণ: https://api.groq.com/openai/v1/chat/completions
এই key অ্যাপের private preferences-এ ফোনে সংরক্ষিত থাকে; চ্যাটের মেসেজের সঙ্গে পাঠানো হয় না। API provider-এর নিজস্ব নীতি/খরচ/সীমা প্রযোজ্য। key কাউকে দেবেন না।

🌱 এটি কীভাবে “শিখে”?

১. এই সংস্করণে আপনি স্মৃতি যোগ/মুছতে পারবেন। ২. স্মৃতিগুলো পরবর্তী প্রশ্নের context হিসেবে মডেলে পাঠানো হয়। ৩. চ্যাট এই ফোনে থাকে। ৪. এটি মডেলের weights বা নিজের কোড নিজে বদলায় না; নতুন ক্ষমতা আনতে মডেল/provider বদল বা app update দরকার। ৫. API ব্যবহার করলে আপনার প্রশ্ন ও স্মৃতি provider-এ যায়—সেই অনুযায়ী সংবেদনশীল তথ্য দেবেন না।
